# 조사 보고서 검토 화면과 동작

v1. [화면 그림](screens-v1.png)의 데이터와 규칙은 모두 가정이다. 표현 범위는 정적 화면이다.

## TASK-01 근거를 확인하고 검토를 완료한다

검토 대기 목록에서 시작해 미확인 0건인 초안을 완료로 저장한다. 출처 실패 시 초안을 유지한 채 재시도하거나 목록으로 돌아간다.

| 화면 | 목적과 정보 | 행동과 결과 | 가이드 |
|---|---|---|---|
| SCR-01 검토 대기 | 보고서 제목·초안 상태·미확인 1건 | ‘초안 검토’ → SCR-02 | [초안 열기](user-guide.md#초안-열기) |
| SCR-02 근거 확인 | 요약·출처·미확인 상태 | ‘출처 보기’로 출처를 연다. 내용 확인 뒤 ‘확인 표시’를 선택하면 미확인 0건. ‘검토 완료로 저장’ → SCR-03 | [근거 확인하기](user-guide.md#근거-확인하기) |
| SCR-03 검토 완료 | 완료 상태·저장 결과 | ‘목록으로’ → 완료 항목이 있는 목록. 완료 항목의 모습은 아직 그리지 않았다. | [완료하기](user-guide.md#완료하기) |
| SCR-04 출처 실패 | 실패 설명·초안 유지 안내 | ‘다시 시도’ → 출처 열기 재시도. ‘나중에 검토’ → 대기 목록 SCR-01 | [출처가 열리지 않을 때](user-guide.md#출처가-열리지-않을-때) |

SCR-02 그림은 미확인 1건이 남아 완료 버튼을 사용할 수 없는 상태다. 확인 후 활성화된 모습·출처 화면·로딩 상태는 다음 시안으로 남겼다.

## 규칙과 사례

| 규칙 | 사례 | 예상 결과 | 근거 |
|---|---|---|---|
| RULE-01 열기와 확인은 별도다 | 출처만 열고 돌아온다 | 미확인 유지 | 예제 가정 |
| RULE-02 미확인이 남으면 완료할 수 없다 | 미확인 1건 | 완료 행동 불가, 이유 표시 | 예제 가정 |
| RULE-02 미확인이 남으면 완료할 수 없다 | 미확인 0건 | 완료 행동 가능, 저장 성공 후 SCR-03 | 예제 가정 |
| RULE-03 출처 실패가 초안을 지우지 않는다 | 출처를 열 수 없다 | SCR-04에서 재시도 또는 나중에 검토 | 예제 가정 |

## 남은 질문과 다음 화면

- ‘확인 표시’의 판단 기준을 기획자와 확인해야 한다.
- 저장 실패·로딩·보고서가 없는 상태가 필요하다.
- 미확인 0건인 SCR-02와 완료 항목이 있는 목록을 그려야 한다.
- 실제 사용자가 근거 확인과 완료 저장의 차이를 이해하는지 관찰해야 한다.
