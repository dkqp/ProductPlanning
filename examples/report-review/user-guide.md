# 조사 초안을 검토하는 방법

정적 시안 v1에 대응하는 목표 경험 초안이다. 예시 제품의 기능과 정책은 가정이다.

## 초안 열기

‘검토 대기’ 목록에서 제목과 미확인 항목 수를 보고 **초안 검토**를 선택한다. 근거 확인 화면이 열린다. [SCR-01과 SCR-02](screens-v1.png)

## 근거 확인하기

요약을 읽고 **출처 보기**를 선택한다. 출처가 요약을 뒷받침하는지 직접 확인한 뒤 **확인 표시**를 선택한다.

출처를 열기만 하면 확인 상태가 바뀌지 않는다. 미확인 항목이 남으면 완료할 수 없다. 확인 판단의 기준은 기획에서 더 구체화할 항목이다.

## 완료하기

모든 항목을 확인하면 **검토 완료로 저장**을 선택한다. 저장이 성공하면 ‘검토 완료’가 나타난다. **목록으로**를 선택해 돌아간다. [SCR-03](screens-v1.png)

버튼의 활성화된 모습과 목록의 완료 상태는 다음 시안에서 추가할 예정이다.

## 출처가 열리지 않을 때

‘출처를 열 수 없어요’에서 **다시 시도**를 선택한다. 계속할 수 없으면 **나중에 검토**를 선택해 목록으로 돌아간다. 초안과 기존 확인 기록은 유지되며 실패한 항목은 미확인으로 남는다. [SCR-04](screens-v1.png)
