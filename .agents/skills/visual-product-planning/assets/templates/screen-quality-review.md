# 화면 품질 평가 기록

## 대상과 확인 범위

- 사용자 역할·핵심 과업:
- 화면·명세·가이드 버전:
- 기기·뷰포트·확대·입력 방법:
- 정적 그림 / 클릭 시안 / 실제 서비스:
- 직접 본 원본·이미지·실행 근거:
- 평가 방식: 자체 / 전문가 / 사용자 관찰:

## 과업별 판정

판정은 확인 / 문제 / 미확인 / 해당 없음이다. 해당 없음에는 이유를 적는다. 정적 화면의 구성·표현과 실제 동작을 구분한다.

| 용어·일관성·인지 부담 | | | |

## 문제 목록

| 문제 ID·위치 | 사실 또는 가설 | 과업에 주는 영향 | 심각도 | 근거 수준 | 수정 또는 결정할 것 | 재검증 |
|---|---|---|---|---|---|---|

심각도는 치명 / 중요 / 경미, 근거는 실제 사용자 관찰 / 실행 점검 / 정적 점검 / 가설로 구분한다. 합산 총점을 만들지 않는다.

## 접근성 근거

| 선택한 성공 기준 | 적용 범위·예외 | 확인 환경·방법·수치 | 판정·남은 확인 |
|---|---|---|---|

색 조합의 대비 수치, 실제 클릭 영역, 키보드·포커스·보조기술·확대 등 확인한 범위만 적는다. 미확인 속성을 통과시키거나 일부 점검으로 전체 준수를 선언하지 않는다.

## 다음 결정

수정 / 사용자 테스트 / 실행 화면 확인 / 범위 변경 중 다음 행동과 담당·버전·완료 기준을 적는다. 핵심 과업의 치명 문제와 중요한 미확인을 어떻게 처리할지 남긴다.
