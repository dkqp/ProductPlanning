# 사용자 테스트 계획과 기록

상태: 계획 / 파일럿 / 실제 세션 / 분석 완료

## 연구 질문과 환경

- 확인하려는 질문·가설:
- 대상 사용자와 모집 기준·제외 기준:
- 참여자 수와 선정 이유:
- 화면·명세·가이드 버전:
- 기기·입력 방법·보조기술·장소:
- 정적 / 클릭 / 실제 서비스와 제약:
- 안내·기록·이용 동의 범위와 보관 위치:
- 파일럿 여부와 수정한 과업:

## 과업 카드

과업별로 복제한다. 참가자에게 읽어 줄 문장과 평가자만 볼 기준을 구분한다.

- 과업 ID·연구 질문:
- 참가자에게 읽을 상황과 목표:
- 시작 조건·데이터:
- 평가자용 완료 조건:
- 가이드·제품 내 도움 사용 허용 범위:
- 진행자 도움·중단 조건:
- 관찰할 행동·상태·오해:
- 시안 제한에 따른 미실행 범위:

## 세션 기록

참가자는 익명 코드로 적는다. 실제 관찰이 없으면 표를 채우지 않는다. 창작 예제·역할극·동료 파일럿은 별도 표시한다.

| 세션·참여자·과업 | 버전·환경 | 결과 | 도움·중단·시간 정의 | 실제 행동·발언 | 해석 | 제안·다음 확인 |
|---|---|---|---|---|---|---|

결과는 독립 완료 / 도움 후 완료 / 미완료 / 미실행·판정 불가다. 시안 제약을 사용자의 실패로 기록하지 않는다. 시간에는 시작·끝·중단의 정의를, 비율에는 분자·분모·제외 이유를 적는다.

## 분석과 다음 결정

| 연구 질문 | 관찰 근거·반대 사례 | 발견과 한계 | 문제·영향 | 조치·담당 | 재검증할 버전·과업 |
|---|---|---|---|---|---|

수정 후 재검증 / 추가 조사 / 범위 변경 / 구현 전환의 이유를 적는다. 실제 사용자 검증 없이 계획만 있는 항목과, 남은 위험을 수용한 결정을 구분한다.
