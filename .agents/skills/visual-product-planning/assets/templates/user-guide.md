# 사용자 가이드

상태: 목표 경험 초안 / 시안과 대조 / 실제 제품에서 확인
대상 화면·제품 버전:

## 첫 결과 얻기

대상 사용자·준비할 것·시작 화면·목표 결과를 적는다. 화면의 실제 문구와 순서를 사용한다.

1. 시작 행동과 보이는 결과.
2. 다음 행동과 보이는 결과.
3. 완료 여부를 확인하는 방법.

관련 화면:

## 과업별 사용법

사용자가 하고 싶은 일을 제목으로 쓰고 전제·행동·결과를 설명한다.

## 실패하거나 잘못 선택했을 때

| 보이는 상황이나 문구 | 사용자가 할 일 | 남아 있는 데이터와 결과 | 관련 화면 |
|---|---|---|---|

## 제한과 참고

행동을 결정하는 데 필요한 제한을 적는다. 항목 설명과 설계 이유는 필요할 때 별도 문서에 연결한다.
